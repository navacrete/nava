# AEGIS – Close Protection Alert

Android εφαρμογή συναγερμού έκτακτης ανάγκης: με ένα πάτημα στέλνει SMS με την
ακριβή τοποθεσία σου στο **112** και στις επαφές έκτακτης ανάγκης σου.

## Λήψη APK

Κάθε push στον φάκελο `aegis-alert/` χτίζει αυτόματα το APK (GitHub Actions) και το
δημοσιεύει στο release **`latest`** του repository:

`https://github.com/navacrete/nava/releases/download/latest/AEGIS.apk`

Στο τηλέφωνο: κατέβασε το αρχείο → άνοιξέ το → επίτρεψε «Εγκατάσταση από άγνωστες πηγές».
Οι ενημερώσεις εγκαθίστανται πάνω στην προηγούμενη έκδοση (ίδιο κλειδί υπογραφής).

## Λειτουργίες

| Λειτουργία | Περιγραφή |
|---|---|
| **SOS με αντίστροφη μέτρηση** | Πάτημα → 5 δευτ. (ρυθμιζόμενο) για ακύρωση → εύρεση GPS → SMS. Παρατεταμένο πάτημα = άμεση αποστολή. |
| **Είδος περιστατικού** | Γενικό SOS, Ιατρικό, Φωτιά, Επίθεση/Αστυνομία, Απαγωγή/Απειλή, Τροχαίο. Κάθε είδος έχει δικό του κείμενο. |
| **Μήνυμα προς 112** | Συμπαγές: είδος, όνομα, συντεταγμένες, link Google Maps, ακρίβεια, ώρα, σημείωση. |
| **Μήνυμα προς επαφές** | Πλήρες: επιπλέον ομάδα αίματος, αλλεργίες, φάρμακα, παθήσεις. |
| **Χρονομετρημένο check-in** | Αν δεν πατήσεις «Είμαι ΟΚ» εγκαίρως, στέλνεται SOS αυτόματα (ακόμη και με κλειστή οθόνη). |
| **Ζωντανή παρακολούθηση** | Αποστολή θέσης στις επαφές κάθε Χ λεπτά (ποτέ στο 112). |
| **Είμαι ασφαλής** | Μήνυμα λήξης συναγερμού με τοποθεσία προς τις επαφές. |
| **Ιστορικό** | Κάθε συναγερμός με κατάσταση παράδοσης SMS ανά παραλήπτη και link χάρτη. |
| **Πλακίδιο Γρήγορων ρυθμίσεων** | «AEGIS SOS» στο μενού ειδοποιήσεων, λειτουργεί και από κλειδωμένη οθόνη. |
| **Συντομεύσεις εικονιδίου** | Παρατεταμένο πάτημα στο εικονίδιο → SOS / Κλήση 112. |
| **Δοκιμαστική λειτουργία** | Όλα τα μηνύματα πηγαίνουν στον δικό σου αριθμό για δοκιμή. **Ποτέ μη δοκιμάζεις με το πραγματικό 112.** |
| **Διακριτική λειτουργία** | Χωρίς δόνηση/ήχο. |

## Τεχνικά

- Kotlin, Android 7.0+ (minSdk 24), target Android 15 (SDK 35).
- Χωρίς Google Play Services: η τοποθεσία προέρχεται από το `LocationManager` (GPS + δίκτυο + fused).
- Χωρίς διαδίκτυο, χωρίς server, χωρίς analytics. Τα δεδομένα μένουν στη συσκευή.
- Build τοπικά: `./gradlew assembleRelease` (απαιτεί Android SDK 35).

## Σημαντικό

Η αποστολή SMS στο 112 εξαρτάται από τον πάροχο και τη χώρα. Στην Ελλάδα το 112 δέχεται SMS,
αλλά η κλήση παραμένει ο πιο γρήγορος τρόπος. Η εφαρμογή προσφέρει πάντα και κουμπί κλήσης.

## Σήμα 112

Το σήμα 112 μέσα στην εφαρμογή είναι vector σχέδιο (`ic_112_badge.xml`) στο ύφος του ευρωπαϊκού
εμβλήματος του ενιαίου αριθμού έκτακτης ανάγκης, που εμφανίζεται στην οθόνη SOS, στα κουμπιά κλήσης
και στις ρυθμίσεις.
