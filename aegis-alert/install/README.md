# Εγκατάσταση AEGIS με αυτόματη άδεια SMS

Σε Android 15+ το Android κλειδώνει την άδεια SMS σε APK που εγκαταστάθηκαν από browser
ή αρχείο. Η εγκατάσταση μέσω ADB δεν έχει αυτόν τον περιορισμό.

- **Windows:** κατέβασε και τρέξε (διπλό κλικ) το `install-aegis-windows.bat`.
- **Mac / Linux:** `bash install-aegis-mac-linux.sh`

Το script κατεβάζει τα Android Platform Tools της Google και το τελευταίο AEGIS.apk,
απεγκαθιστά την παλιά έκδοση και εγκαθιστά τη νέα μέσω ADB.

Στο κινητό πρέπει πρώτα να είναι ενεργό το **USB debugging**
(Ρυθμίσεις → Σχετικά με το τηλέφωνο → 7 πατήματα στον «Αριθμό έκδοσης» → Επιλογές προγραμματιστή).

**Χωρίς υπολογιστή:** εγκατάστησε το **Shizuku** από το Play Store, ξεκίνησέ το με
«Wireless debugging», και εγκατάστησε το AEGIS.apk μέσα από αυτό. Μετράει ως ADB.
