# Η Κάρτα Μου (Android APK)

Προσωπική εφαρμογή για **έναν** εργαζόμενο: δύο κουμπιά, **ΠΡΟΣΕΛΕΥΣΗ** και **ΑΠΟΧΩΡΗΣΗ**, που
καταχωρούν το χτύπημα της ψηφιακής κάρτας μέσω του eVardia **ακριβώς όπως η σελίδα «Αποστολή από
Camera»**, χωρίς σκανάρισμα QR. Ανεξάρτητη από οτιδήποτε άλλο (WordPress, plugin SMS κ.λπ.).

## Τι κάνει ακριβώς

Η σελίδα της κάμερας του eVardia χρησιμοποιεί το QR μόνο για να διαβάσει το ΑΦΜ και μετά:

1. `GET /Ergazomenos/GetErgazomenosByAfm?etaireiaId=124&afm=ΑΦΜ` (εμφανίζει το όνομα),
2. `POST /Ergazomenos/Dhlosh` με JSON `{serialNumber:"36122", afmErgazomenou:"ΑΦΜ", TyposDhloshs:"0"|"1", progr:"Camera"}`.

Η εφαρμογή κάνει τα ίδια δύο αιτήματα με τους **κωδικούς σκάνερ** (session cookie μετά από login) και
τίποτα άλλο. Το `0` είναι προσέλευση, το `1` αποχώρηση. Η ώρα είναι η ώρα του πατήματος.

## Εγκατάσταση

1. Αντιγράψτε το `build/kartamou.apk` στο κινητό (email, USB, Drive) και ανοίξτε το. Αν ρωτήσει για
   «άγνωστες πηγές», επιτρέψτε την εγκατάσταση για αυτή τη μία φορά.
2. Με το πρώτο άνοιγμα ανοίγουν οι **Ρυθμίσεις**: όνομα χρήστη/κωδικός eVardia **σκάνερ**, το
   **ΑΦΜ** σας, προαιρετικό **PIN**. Τα `serialNumber` (36122) και `etaireiaId` (124) είναι
   προσυμπληρωμένα από τη σελίδα του eVardia· αλλάξτε τα μόνο αν αλλάξουν εκεί.
3. Πατήστε ΠΡΟΣΕΛΕΥΣΗ → PIN → «ΝΑΙ, στείλε». Η απάντηση του eVardia εμφανίζεται με ✓ ή ✗ και
   κρατιέται μικρό ιστορικό στην οθόνη.

Οι ρυθμίσεις αποθηκεύονται στον ιδιωτικό χώρο της εφαρμογής στο κινητό (δεν βγαίνουν σε backup).

## Χτίσιμο χωρίς Android SDK

Το `tools/build.sh` χτίζει το APK μόνο με Java 17+ και τέσσερα jar σε έναν φάκελο `$TC`:

| Αρχείο | Πηγή |
| --- | --- |
| `android-all.jar` | Maven Central: `org.robolectric:android-all:15-robolectric-12650502` (framework για javac) |
| `dx.jar` | Maven Central: `com.jakewharton.android.repackaged:dalvik-dx:14.0.0_r21` |
| `apktool.jar` | GitHub iBotPeaches/Apktool v2.10.0 (περιέχει aapt2 και framework resources) |
| `signer.jar` | GitHub patrickfav/uber-apk-signer v1.3.0 |

```
TC=/path/to/jars bash tools/build.sh      # -> build/kartamou.apk
```

Το `tools/kartamou.keystore` (κωδικός `kartamou`) υπογράφει το APK. Κρατήστε το: μια νέα έκδοση πρέπει
να υπογραφεί με το ίδιο κλειδί για να εγκατασταθεί πάνω στην παλιά χωρίς απεγκατάσταση.

Με Android Studio: `src/` είναι απλή Java χωρίς εξαρτήσεις (ούτε AndroidX), `AndroidManifest.xml` και
`res/` είναι τυπικά· μπορεί να μπει σε οποιοδήποτε νέο project «No Activity».

## Σημειώσεις

- Πατήστε το κουμπί **μόνο τη στιγμή** της προσέλευσης ή αποχώρησης. Για το eVardia και την ΕΡΓΑΝΗ
  είναι ένα χτύπημα από σκάνερ, με την τρέχουσα ώρα.
- Αν το eVardia επιστρέψει «Παρακαλώ προσπαθήστε πάλι σε 2 λεπτά», είναι το ίδιο μήνυμα που δείχνει και
  η σελίδα της κάμερας (δύο χτυπήματα πολύ κοντά).
- Οι κωδικοί σκάνερ δεν μπορούν να κάνουν τίποτα άλλο στο eVardia, οπότε αν χαθεί το κινητό, το μόνο
  που μπορεί να κάνει κάποιος με την εφαρμογή (χωρίς PIN) είναι ένα χτύπημα με το ΑΦΜ σας.
