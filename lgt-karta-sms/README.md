# LGT Κάρτα Εργασίας SMS (WordPress plugin)

Παίρνει αυτόματα τα χτυπήματα της ψηφιακής κάρτας εργασίας από το eVardia, βρίσκει ποιοι έχουν
βάρδια σήμερα αλλά **δεν έχουν χτυπήσει κάρτα** μέχρι το όριο ανοχής και τους στέλνει **SMS**
(και, προαιρετικά, SMS/email στον υπεύθυνο). Ανεξάρτητο από το plugin «LGT School Trips».

## Πώς δουλεύει

1. Στους **Εργαζόμενους** δηλώνετε όνομα, κινητό ή/και email, κωδικό στο eVardia (ή ΑΦΜ) και ώρα
   έναρξης βάρδιας ανά ημέρα (κενό = ρεπό). Ανά εργαζόμενο υπάρχουν **δύο ανεξάρτητοι διακόπτες**:
   «ειδοποιείται ο ίδιος» και «ειδοποιείται ο υπεύθυνος γι’ αυτόν» (κάθε συνδυασμός, π.χ. διευθυντής:
   μόνο ο ίδιος ή κανείς), και το **κανάλι** προς τον εργαζόμενο (SMS, Email, SMS + Email). Οι εξαιρέσεις αποθηκεύονται και
   φαίνονται συγκεντρωτικά στη σελίδα «Εργαζόμενοι». Υπάρχει μαζική προσθήκη με επικόλληση από Excel.
2. Κάθε 5 λεπτά (WP-Cron ή εξωτερικό cron URL) το plugin:
   - βλέπει ποιοι έχουν περάσει το όριο (έναρξη + ανοχή, π.χ. 09:00 + 15′),
   - **μόνο αν εκκρεμεί κάποιος**, τραβάει τα σημερινά χτυπήματα από το eVardia,
   - σε όποιον δεν έχει χτύπημα στέλνει SMS ή/και email κατά το κανάλι του (μία φορά, προαιρετικά
     και 2η υπενθύμιση)· όσοι έχουν «Κανείς» παραλείπονται, όσοι έχουν «Μόνο υπεύθυνος» ειδοποιούν μόνο τον υπεύθυνο,
   - ενημερώνει τους υπευθύνους με SMS, email ή και τα δύο (ρύθμιση «Ειδοποίηση υπευθύνων»),
   - μετά τη «μέγιστη καθυστέρηση» (π.χ. 3 ώρες) σταματά να ασχολείται (απουσία).
3. Στο **Σήμερα** βλέπετε live ποιος χτύπησε, ποιος όχι, τι SMS έφυγαν, και μπορείτε να σημειώσετε
   χτύπημα χειροκίνητα, να στείλετε ειδοποίηση με ένα κλικ, ή να στείλετε **email στους υπευθύνους με
   τη συνολική κατάσταση της ημέρας** (ποιος χτύπησε / δεν χτύπησε / σε αναμονή). Στο **Ιστορικό** όλα τα SMS με την απάντηση
   του παρόχου.

## Πώς «παίρνει» τα χτυπήματα από το eVardia

Το eVardia (Anaconda) δεν δημοσιεύει ανοιχτό API, οπότε το plugin υποστηρίζει **έξι** τρόπους·
ο πρώτος δεν χρειάζεται τίποτα από την Anaconda· για τους επόμενους ρωτήστε το support τους:

| Τρόπος | Τι χρειάζεται από το eVardia |
| --- | --- |
| **eVardia με κωδικούς (προεπιλογή)** | Μόνο όνομα χρήστη/κωδικό eVardia. Το plugin συνδέεται στο evardia.gr και διαβάζει τη σελίδα «Επιλεκτική αποστολή» (`/Ergazomenos/EpilektikhApostolh?fetchAll=False`), που περιέχει για κάθε εργαζόμενο με βάρδια σήμερα: ΑΦΜ, ονοματεπώνυμο, υποκατάστημα, έως 3 βάρδιες (Από/Έως) και τις ώρες Προσ/ση – Αποχ/ση. Οι εργαζόμενοι προστίθενται αυτόματα με ΑΦΜ, **το ωράριο ημέρας έρχεται από το eVardia** (δεν πληκτρολογείτε ωράρια) και τα χτυπήματα καταγράφονται. Εσείς συμπληρώνετε μόνο κινητό/email και κανάλι. Μόνο ανάγνωση. Αν η Anaconda αλλάξει τη σελίδα, θέλει προσαρμογή. |
| **Σύνδεση με κωδικούς (web login)** | Τίποτα από την Anaconda: το plugin κάνει login στο evardia.gr με το όνομα χρήστη/κωδικό σας, κρατά τη συνεδρία και διαβάζει τη σελίδα ή αναφορά με τα χτυπήματα της ημέρας (πίνακας HTML, JSON ή CSV). Χρειάζεται μία φορά το URL login, το URL της αναφοράς και τις επικεφαλίδες των στηλών. Εξαρτάται από τη δομή του site του eVardia· αν αλλάξει, θέλει ξαναρύθμιση. |
| **API (JSON)** | URL που επιστρέφει τα χτυπήματα της ημέρας + API key. Δηλώνετε τη διαδρομή της λίστας (`data.records`) και τα ονόματα πεδίων (εργαζόμενος, ώρα, είσοδος/έξοδος). |
| **CSV από URL** | Σύνδεσμος export (CSV) των χτυπημάτων. Δηλώνετε όνομα ή αριθμό στήλης. |
| **Webhook** | Αν το eVardia μπορεί να «χτυπάει» ένα URL σε κάθε χτύπημα (ή μέσω Zapier/Make/n8n), του δίνετε το URL `…/wp-json/lgt-karta/v1/punch?token=…`. |
| **Χειροκίνητα** | Χωρίς σύνδεση· η παρουσία σημειώνεται από τον πίνακα «Σήμερα». Το SMS φεύγει αυτόματα σε όσους δεν σημειώθηκαν. |

Η αντιστοίχιση εργαζόμενου γίνεται με **κωδικό eVardia / ΑΦΜ**, αλλιώς με **κινητό**, αλλιώς με
**ονοματεπώνυμο** (ανεξαρτήτως τόνων, κεφαλαίων και σειράς ονόματος/επωνύμου). Στο κουμπί
«Δοκιμή πηγής» βλέπετε τι επιστρέφει το eVardia και ποιοι δεν αντιστοιχίστηκαν.

Ημερομηνίες: αναγνωρίζει αυτόματα ISO (`2026-10-01T09:02:00`), `01/10/2026 09:02`, Unix
timestamp· αλλιώς δηλώνετε μορφή PHP (π.χ. `d/m/Y H:i:s`). Στα URL μπορείτε να βάλετε `{date}`,
`{date_dmy}`, `{from}`, `{to}` κ.λπ. για τη σημερινή ημέρα.

## Αποστολή SMS

Ρυθμίσεις → Αποστολή SMS. Προεπιλογή **Yuboto** (OMNI API v1.3, `POST
https://services.yuboto.com/omni/v1/Send`, Basic auth με το API key, body
`{"phonenumbers":["3069…"],"sms":{"sender","text","typesms","longsms","validity"}}`). Χρειάζεται μόνο
το **OMNI API key** από την πλατφόρμα Yuboto (My Account → API Integration) ή από
support@yuboto.com. Το plugin επιλέγει αυτόματα `typesms: unicode` όταν το μήνυμα έχει ελληνικά
(70 χαρακτήρες/τμήμα) και ενεργοποιεί `longsms` για μεγαλύτερα μηνύματα. Κουμπί «Υπόλοιπο
λογαριασμού» ελέγχει το key χωρίς αποστολή. Η απάντηση (ErrorCode, status ανά αριθμό, message id)
καταγράφεται στο Ιστορικό.

Εναλλακτικά: **Routee**, **Twilio**, ή **«Γενικό HTTP API»** για οποιονδήποτε άλλον πάροχο
(EasySMS, SMS.to, Apifon, Vonage…): URL, headers, body με μεταβλητές `{to}` `{message}` `{sender}`.
Υπάρχει «Δοκιμαστικό SMS» που δείχνει την απάντηση του παρόχου. Το Sender ID (π.χ. `LeGrand`)
πρέπει να έχει εγκριθεί στον πάροχο.

## Μόνο ανάγνωση από το eVardia (τεχνική εγγύηση)

Η κλάση `LGTKS_Guard` συνδέεται στο φίλτρο `pre_http_request` του WordPress και ελέγχει **κάθε**
εξερχόμενο αίτημα προς τους διακομιστές του eVardia (και όποιου άλλου web login οριστεί). Επιτρέπονται
μόνο GET στη σελίδα «Επιλεκτική αποστολή», στην αρχική και στη σελίδα σύνδεσης, και ένα μόνο POST: η
φόρμα σύνδεσης, και μόνο τη στιγμή που το plugin κάνει login. Οτιδήποτε άλλο (POST/PUT/DELETE,
άλλες σελίδες) ακυρώνεται πριν σταλεί, καταγράφεται ως σφάλμα και εμφανίζεται στο «Αρχείο ελέγχου»
των Ρυθμίσεων, που δείχνει τα τελευταία 60 αιτήματα με μέθοδο, σελίδα και αποτέλεσμα.

## ΕΡΓΑΝΗ

Το επίσημο Web API της ΕΡΓΑΝΗ (eservices.yeka.gr/WebservicesAPI) επιτρέπει **υποβολή** χτυπημάτων
και ανάγνωση στοιχείων εργοδότη/παραρτημάτων/προσωπικού (υπηρεσίες EX_BASE_01…06), αλλά **δεν
επιστρέφει τα μεμονωμένα χτυπήματα κάρτας**. Γι' αυτό το plugin δεν μπορεί να διαβάσει τα χτυπήματα
απευθείας από την ΕΡΓΑΝΗ με τους κωδικούς της εταιρείας· η πηγή πρέπει να είναι το σύστημα όπου
χτυπάνε οι εργαζόμενοι (eVardia, ρολόι, κ.λπ.).

## Εγκατάσταση

1. Πρόσθετα → Προσθήκη νέου → Μεταφόρτωση → `lgt-karta-sms.zip` → Ενεργοποίηση.
2. **Κάρτα Εργασίας SMS → Ρυθμίσεις**: πάροχος SMS (+ δοκιμαστικό SMS), πηγή χτυπημάτων
   (+ δοκιμή πηγής), ανοχή, μήνυμα, κινητά υπευθύνων, αργίες.
3. **Εργαζόμενοι**: προσθήκη με ωράριο.
4. Για σίγουρη εκτέλεση κάθε 5′ (το WP-Cron τρέχει μόνο όταν έχει επισκέψεις το site), βάλτε στο
   hosting ή στο cron-job.org το URL `…/wp-json/lgt-karta/v1/run?token=…` που φαίνεται στις ρυθμίσεις.
5. Όταν όλα δουλεύουν, τσεκάρετε **«Αυτόματες ειδοποιήσεις: Ενεργές»**.

Απαιτήσεις: WordPress 6.0+, PHP 7.4+. Χωρίς εξωτερικές βιβλιοθήκες.

```
includes/class-lgtks-db.php       εργαζόμενοι, χτυπήματα, ειδοποιήσεις, log
includes/class-lgtks-source.php   λήψη χτυπημάτων: JSON API / CSV / webhook, αντιστοίχιση
includes/class-lgtks-evardia.php  eVardia: login, ανάγνωση «Επιλεκτικής αποστολής», ωράρια + χτυπήματα, auto-εργαζόμενοι
includes/class-lgtks-weblogin.php γενικό login με κωδικούς σε web εφαρμογή + ανάγνωση πίνακα/JSON/CSV
includes/class-lgtks-sms.php      Yuboto / Routee / Twilio / γενικό HTTP
includes/class-lgtks-checker.php  ο έλεγχος: ποιος εκκρεμεί, αποστολή SMS, 2η υπενθύμιση
includes/class-lgtks-rest.php     REST: /punch (webhook), /run (εξωτερικό cron)
includes/class-lgtks-cron.php     WP-Cron κάθε 5 λεπτά
includes/class-lgtks-admin.php    Σήμερα / Εργαζόμενοι / Ρυθμίσεις / Ιστορικό
```
