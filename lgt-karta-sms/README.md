# LGT Κάρτα Εργασίας SMS (WordPress plugin)

Παίρνει αυτόματα τα χτυπήματα της ψηφιακής κάρτας εργασίας από το eVardia, βρίσκει ποιοι έχουν
βάρδια σήμερα αλλά **δεν έχουν χτυπήσει κάρτα** μέχρι το όριο ανοχής και τους στέλνει **SMS**
(και, προαιρετικά, SMS/email στον υπεύθυνο). Ανεξάρτητο από το plugin «LGT School Trips».

## Πώς δουλεύει

1. Στους **Εργαζόμενους** δηλώνετε όνομα, κινητό, κωδικό στο eVardia (ή ΑΦΜ) και ώρα έναρξης
   βάρδιας ανά ημέρα (κενό = ρεπό). Υπάρχει μαζική προσθήκη με επικόλληση από Excel.
2. Κάθε 5 λεπτά (WP-Cron ή εξωτερικό cron URL) το plugin:
   - βλέπει ποιοι έχουν περάσει το όριο (έναρξη + ανοχή, π.χ. 09:00 + 15′),
   - **μόνο αν εκκρεμεί κάποιος**, τραβάει τα σημερινά χτυπήματα από το eVardia,
   - σε όποιον δεν έχει χτύπημα στέλνει SMS (μία φορά, προαιρετικά και 2η υπενθύμιση),
   - ενημερώνει τον υπεύθυνο με SMS/email,
   - μετά τη «μέγιστη καθυστέρηση» (π.χ. 3 ώρες) σταματά να ασχολείται (απουσία).
3. Στο **Σήμερα** βλέπετε live ποιος χτύπησε, ποιος όχι, τι SMS έφυγαν, και μπορείτε να σημειώσετε
   χτύπημα χειροκίνητα ή να στείλετε SMS με ένα κλικ. Στο **Ιστορικό** όλα τα SMS με την απάντηση
   του παρόχου.

## Πώς «παίρνει» τα χτυπήματα από το eVardia

Το eVardia (Anaconda) δεν δημοσιεύει ανοιχτό API, οπότε το plugin υποστηρίζει **τέσσερις** τρόπους·
ρωτήστε το support της Anaconda ποιον από τους δύο πρώτους σας δίνουν:

| Τρόπος | Τι χρειάζεται από το eVardia |
| --- | --- |
| **API (JSON)** | URL που επιστρέφει τα χτυπήματα της ημέρας + API key. Δηλώνετε τη διαδρομή της λίστας (`data.records`) και τα ονόματα πεδίων (εργαζόμενος, ώρα, είσοδος/έξοδος). |
| **CSV από URL** | Σύνδεσμος export (CSV) των χτυπημάτων. Δηλώνετε όνομα ή αριθμό στήλης. |
| **Webhook** | Αν το eVardia μπορεί να «χτυπάει» ένα URL σε κάθε χτύπημα (ή μέσω Zapier/Make/n8n), του δίνετε το URL `…/wp-json/lgt-karta/v1/punch?token=…`. |
| **Χειροκίνητα** | Χωρίς σύνδεση· η παρουσία σημειώνεται από τον πίνακα «Σήμερα». Το SMS φεύγει αυτόματα σε όσους δεν σημειώθηκαν. |

Η αντιστοίχιση εργαζόμενου γίνεται με **κωδικό eVardia / ΑΦΜ**, αλλιώς με **κινητό**, αλλιώς με
**ονοματεπώνυμο** (ανεξαρτήτως τόνων, κεφαλαίων και σειράς ονόματος/επωνύμου). Στο κουμπί
«Δοκιμή πηγής» βλέπετε τι επιστρέφει το eVardia και ποιοι δεν αντιστοιχίστηκαν.

Ημερομηνίες: αναγνωρίζει αυτόματα ISO (`2026-10-01T09:02:00`), `01/10/2026 09:02`, Unix
timestamp· αλλιώς δηλώνετε μορφή PHP (π.χ. `d/m/Y H:i:s`). Στα URL μπορείτε να βάλετε `{date}`,
`{date_dmy}`, `{from}`, `{to}` κ.λπ. για τη σημερινή ημέρα.

## Αποστολή SMS

Ρυθμίσεις → Αποστολή SMS. Έτοιμες επιλογές: **Yuboto**, **Routee**, **Twilio**, και **«Γενικό HTTP
API»** για οποιονδήποτε άλλον πάροχο (EasySMS, SMS.to, Apifon, Vonage…): URL, headers, body με
μεταβλητές `{to}` `{message}` `{sender}`. Υπάρχει «Δοκιμαστικό SMS» που δείχνει την απάντηση του
παρόχου. Το Sender ID (π.χ. `LeGrand`) πρέπει να έχει εγκριθεί στον πάροχο. Τα ελληνικά στέλνονται
ως Unicode (70 χαρακτήρες ανά τμήμα).

## Εγκατάσταση

1. Πρόσθετα → Προσθήκη νέου → Μεταφόρτωση → `lgt-karta-sms.zip` → Ενεργοποίηση.
2. **Κάρτα Εργασίας SMS → Ρυθμίσεις**: πάροχος SMS (+ δοκιμαστικό SMS), πηγή χτυπημάτων
   (+ δοκιμή πηγής), ανοχή, μήνυμα, κινητά υπευθύνων, αργίες.
3. **Εργαζόμενοι**: προσθήκη με ωράριο.
4. Για σίγουρη εκτέλεση κάθε 5′ (το WP-Cron τρέχει μόνο όταν έχει επισκέψεις το site), βάλτε στο
   hosting ή στο cron-job.org το URL `…/wp-json/lgt-karta/v1/run?token=…` που φαίνεται στις ρυθμίσεις.
5. Όταν όλα δουλεύουν, τσεκάρετε **«Αυτόματες ειδοποιήσεις: Ενεργές»**.

Απαιτήσεις: WordPress 6.0+, PHP 7.4+. Χωρίς εξωτερικές βιβλιοθήκες.

## Δομή

```
lgt-karta-sms.php                 bootstrap
includes/class-lgtks-install.php  πίνακες (employees, punches, notifications, log), cron
includes/class-lgtks-settings.php ρυθμίσεις, αργίες, headers
includes/class-lgtks-db.php       εργαζόμενοι, χτυπήματα, ειδοποιήσεις, log
includes/class-lgtks-source.php   λήψη χτυπημάτων: JSON API / CSV / webhook, αντιστοίχιση
includes/class-lgtks-sms.php      Yuboto / Routee / Twilio / γενικό HTTP
includes/class-lgtks-checker.php  ο έλεγχος: ποιος εκκρεμεί, αποστολή SMS, 2η υπενθύμιση
includes/class-lgtks-rest.php     REST: /punch (webhook), /run (εξωτερικό cron)
includes/class-lgtks-cron.php     WP-Cron κάθε 5 λεπτά
includes/class-lgtks-admin.php    Σήμερα / Εργαζόμενοι / Ρυθμίσεις / Ιστορικό
```
