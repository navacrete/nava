# LGT School Trips – Σχολικές Εκδρομές (WordPress plugin)

Πλατφόρμα για τα σχολεία που ταξιδεύουν με τη Le Grand Travel: το σχολείο καταχωρεί
μαθητές και συνοδούς μέσα από έναν προσωπικό σύνδεσμο, φτιάχνει δωμάτια ξενοδοχείου
και καμπίνες πλοίου, και το γραφείο λαμβάνει αυτόματα rooming lists και manifests σε
Excel και PDF, με λατινικούς χαρακτήρες (ΕΛΟΤ 743, όπως στις ταυτότητες/διαβατήρια).

## Τι κάνει

| Ανάγκη | Πώς καλύπτεται |
| --- | --- |
| Καταχώρηση μαθητών από το σχολείο | Σύνδεσμος `/school-trip/{κωδικός}/` χωρίς login, με προαιρετικό κωδικό πρόσβασης. Προσθήκη ένα-ένα ή μαζική επικόλληση από Excel με αυτόματη αναγνώριση στηλών. |
| Rooming list στα λατινικά | Αυτόματη μεταγραφή ΕΛΟΤ 743 (Μπάμπης → BAMPIS, Ευθύμιος → EFTHYMIOS, Παπαδόπουλος → PAPADOPOULOS) με δυνατότητα χειροκίνητης διόρθωσης και «κλειδώματος». |
| Καμπίνες πλοίου με ονόματα | Καρτέλα «Καμπίνες» με drag & drop, τύπους καμπινών (AB2/AB3/AB4/A4, ρυθμιζόμενοι) και manifest επιβατών (φύλο, ημ. γέννησης, εθνικότητα, ΑΔΤ). |
| Αεροπορικά όπως ζητούν οι εταιρείες | Λίστα με Title (MR/MS/MSTR/MISS), ονόματα όπως στο έγγραφο, ημ. γέννησης, PAX (ADT/CHD/INF υπολογισμένο στην ημέρα αναχώρησης), εθνικότητα, τύπο/αριθμό/λήξη εγγράφου. |
| Σχολείο με αεροπορικό **ή** ακτοπλοϊκό **ή** και τα δύο | Σε κάθε εκδρομή τσεκάρετε Ξενοδοχείο / Πλοίο / Αεροπλάνο. Τα υποχρεωτικά πεδία, οι καρτέλες και οι λίστες προσαρμόζονται αυτόματα. |
| Ίδιες παρέες σε καμπίνα και δωμάτιο | Κουμπί «Αντιγραφή από καμπίνες/δωμάτια»: οι ίδιες ομάδες μεταφέρονται στον άλλο τύπο διαμονής και ξαναπακετάρονται έξυπνα όταν οι χωρητικότητες διαφέρουν (π.χ. 4κλινη καμπίνα → 2 δίκλινα). |
| Αυτόματα Excel/PDF στο γραφείο | Με κάθε «Υποβολή» του σχολείου, με «Αποστολή τώρα» από το γραφείο, με τις υπενθυμίσεις και (προαιρετικά) με ημερήσια ενημέρωση όταν ένα σχολείο κάνει αλλαγές. Παραλήπτες στις Ρυθμίσεις. |
| Σύνδεσμος που κλείνει το γραφείο | Ο σύνδεσμος δεν λήγει ποτέ μόνος του. «Κλείσιμο καταχώρησης» → το σχολείο βλέπει και κατεβάζει, δεν αλλάζει. «Άνοιγμα» ξανά όποτε θέλετε. |
| Υπενθυμίσεις πριν την εκδρομή | Ρυθμιζόμενες ημέρες (π.χ. 30,14,7,3,1) και ώρα. Γραφείο (με συνημμένα), σχολείο, επιπλέον emails ανά εκδρομή (συνοδοί, ξενοδοχείο). |

Επιπλέον: αυτόματη κατανομή ανά φύλο/τμήμα χωρίς να μένει κανείς μόνος όπου γίνεται,
έλεγχος πληρότητας/ελλείψεων ανά άτομο, έλεγχος λήξης εγγράφων, ακυρώσεις μαθητών,
ιστορικό ενεργειών και αρχείο email ανά εκδρομή, πλήρης λίστα (ελληνικά + λατινικά)
για εσωτερική χρήση.

## Εγκατάσταση

1. Ανεβάστε τον φάκελο `lgt-school-trips` στο `wp-content/plugins/` (ή zip → Πρόσθετα → Μεταφόρτωση).
2. Ενεργοποιήστε το από τα Πρόσθετα. Δημιουργούνται οι πίνακες και προγραμματίζεται η ημερήσια εργασία.
3. Μενού **Σχολικές Εκδρομές → Ρυθμίσεις**: emails γραφείου, αποστολέας, ημέρες υπενθύμισης, επωνυμία/τηλέφωνο, λογότυπο (JPG) για τα PDF.
4. Προτείνεται SMTP plugin (π.χ. WP Mail SMTP) ώστε τα email με συνημμένα να παραδίδονται αξιόπιστα. Υπάρχει κουμπί «Αποστολή δοκιμαστικού email».
5. Αν χρησιμοποιείτε «απλούς» permalinks, οι σύνδεσμοι έχουν τη μορφή `?lgt_trip_token=…` και λειτουργούν επίσης.

Απαιτήσεις: WordPress 6.0+, PHP 7.4+ (δοκιμασμένο σε PHP 8.4), επέκταση `zip` για Excel (αλλιώς παράγεται CSV). Δεν χρειάζονται εξωτερικές βιβλιοθήκες.

## Ροή εργασίας (γραφείο: 1 λεπτό, τα υπόλοιπα τα κάνει το σχολείο)

1. **Νέα εκδρομή**: σχολείο, email σχολείου, προορισμός, ημερομηνίες, τι περιλαμβάνει (ξενοδοχείο / πλοίο / αεροπλάνο) → «Δημιουργία & αποστολή στο σχολείο». Ο σύνδεσμος φεύγει αυτόματα με email. Όλα τα υπόλοιπα (τίτλος, τύποι δωματίων, κωδικός, σημειώσεις) είναι προαιρετικά.
2. Το σχολείο ανοίγει τον σύνδεσμο και βλέπει 3 βήματα:
   - **Ονόματα**: πίνακας σαν Excel, γράφει κατευθείαν μέσα (ή επικολλά ολόκληρη τη λίστα του με Ctrl+V). Τα λατινικά συμπληρώνονται μόνα τους, το φύλο εκτιμάται από το όνομα, οι ημερομηνίες γράφονται ηη/μμ/εεεε. Κάθε γραμμή αποθηκεύεται αυτόματα.
   - **Δωμάτια / Καμπίνες**: στήλες Μονόκλινα / Δίκλινα / Τρίκλινα / Τετράκλινα με κουτάκια δωματίων, όπως η χάρτινη rooming list. Διαλέγει όνομα σε κάθε θέση, σέρνει ονόματα, ή πατά «Αυτόματη κατανομή». «Ίδιες παρέες» αντιγράφει την κατανομή από καμπίνες σε δωμάτια και αντίστροφα.
   - **Υποβολή**: ένα κουμπί. Το γραφείο λαμβάνει Excel + PDF, το σχολείο επιβεβαίωση.
3. Στη λίστα εκδρομών βλέπετε πού βρίσκεται κάθε σχολείο («Περιμένουμε το σχολείο», «Το σχολείο καταχωρεί», «Υποβλήθηκε») και κατεβάζετε Excel/PDF με ένα κλικ. Κλείνετε την καταχώρηση όταν οριστικοποιηθεί.
4. Οι υπενθυμίσεις φεύγουν αυτόματα τις ρυθμισμένες ημέρες πριν την αναχώρηση.

## Δομή

```
lgt-school-trips.php            bootstrap
includes/class-lgt-install.php  πίνακες, δικαιώματα, cron
includes/class-lgt-db.php       data layer (trips, participants, rooms, assignments, logs)
includes/class-lgt-rest.php     REST API /wp-json/lgt/v1 (κοινό για σχολείο & γραφείο)
includes/class-lgt-portal.php   δημόσια σελίδα /school-trip/{token}
includes/class-lgt-admin.php    σελίδες διαχείρισης & ρυθμίσεων
includes/class-lgt-allocator.php  έξυπνη κατανομή δωματίων / καμπινών
includes/class-lgt-transliterator.php  ΕΛΟΤ 743
includes/class-lgt-validator.php  υποχρεωτικά πεδία ανά τύπο μεταφοράς
includes/class-lgt-exporter.php   datasets → Excel / PDF
includes/class-lgt-xlsx-writer.php, class-lgt-pdf-writer.php   writers χωρίς εξαρτήσεις
includes/class-lgt-mailer.php, class-lgt-cron.php   emails, υπενθυμίσεις, digest
assets/js/app.js, assets/css/app.css   η εφαρμογή (portal + admin)
templates/                        σελίδες portal
```

## Ασφάλεια

- Οι σύνδεσμοι είναι 32 τυχαίοι χαρακτήρες, με προαιρετικό κωδικό πρόσβασης ανά εκδρομή (cookie με HMAC).
- Το REST API δέχεται εγγραφές μόνο για «ανοιχτές» εκδρομές με έγκυρο token, ή από συνδεδεμένους χρήστες με το δικαίωμα `lgt_manage_trips` (δίνεται στους διαχειριστές).
- Τα παραγόμενα αρχεία δημιουργούνται προσωρινά σε προστατευμένο φάκελο στο `uploads/lgt-school-trips/` και διαγράφονται μετά την αποστολή.
- Η σελίδα του portal είναι `noindex` και δεν εξαρτάται από το θέμα.
